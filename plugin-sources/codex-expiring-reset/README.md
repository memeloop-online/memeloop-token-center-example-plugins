# 历史临期重置插件

此目录保留旧版本的源码与回归证据。当前安装入口为 `mtc-soonest-reset` 的“额度管理”，同时提供额度分配和临期重置。旧独立发布工作流已归档到 `docs/archived-workflows/`。

# Codex 手动重置次数到期前使用

独立、需宿主明确授权的后台插件。在真正可用的 Codex 手动重置次数
`expires_at` 前 **10 分钟**至到期前，规划使用最早到期的一次。
配置为 `{}`，时间固定且不可调；每 60 秒由宿主调用一次。
选择依据为手动重置次数的 `expires_at`。

安装后在侧边栏「自动化 → Codex 到期重置」选择 Codex 账号，查看可用次数、
最近到期时间和执行记录，并为该账号开启或关闭自动使用。浏览器页面调用
当前租户的后台授权接口，保存时使用 revision 冲突检查。读取权限对应只读界面；
待核实结果显示相关记录入口。实际 resetcredit 由宿主后台执行。

插件仅导出 `memeloop:background-actions/planner@0.1.0`，没有宿主导入、
HTTP、密钥、令牌、读写存储或直接调用 resetcredit 的能力。
输入必须来自宿主筛选的可用次数；缺少有效时间或授权上下文时不产生 intent。
多个次数按到期时间、指纹排序；已到期的次数不选择。短期次数的生效时间
不早于发放时间。每次选择仅返回一个原样的次数指纹、库存指纹和时间范围。
相同库存及时间范围内的重复调用产生相同 intent；宿主持久幂等记录保证
同一业务操作最多派发一次，插件使用纯函数规划。

宿主负责租户/账户/授权版本隔离、最新库存确认、执行前再校验、互斥、
持久幂等及未知结果的核实流程。租户与执行身份由宿主授权检查确认，
宿主构建可信的 typed context。

本目录包含与宿主完全一致的无 imports WIT 和单测定义。专用 CI 运行
边界、确定性、最早到期、无效上下文及配置拒绝测试，并构建验证组件，
将 manifest、组件和说明作为未签名 review 包上传。
同一包包含仅使用宿主 React/Fluent 的单文件 operator UI；独立 CI 浏览器脚本
对真实打包入口进行开关、账号搜索、权限、租户切换、冲突和异常状态验证，
并上传桌面及手机截图。浏览器使用合成 fixture，不请求真实供应商。
`Cargo.lock` 复用既有 soonest-reset 的依赖锁，仅改本 crate 名称，无新增依赖。
本地不运行编译、测试或安装依赖。

该包需要支持 `quota_reset_credit` 的新宿主及安装器。签名发布使用包含
本能力的新宿主完成真实组件验收后，取得的官方发布 digest 和审核过的发布 pin。
CI review artifact 用于代码与浏览器审查；签名发布、安装、账号授权分别执行。
